Prompt Injection

Prompt injection happens when text inside a user request or external content tries to change how an AI application is supposed to behave. The injected text may look like normal content, but the model may treat it as an instruction.

Trusted vs Untrusted

Instructions vs content

Trusted Instructions

Come from the application or an authorized user. They define the task.

Summarize the file.
Use only approved sources.
Ask before sending an email.
Untrusted Content

Comes from outside the application. It is data for the task — not commands.

Documents and files
Websites and emails
Records retrieved by RAG
Messages from unknown senders
Instructions define the task. Content provides data for the task. AI systems may not always separate the two reliably.

Important Distinction

Prompt injection vs jailbreaking

Prompt Injection

Targets an AI application and tries to change its intended task or behaviour.

Targets application instructions
May come from the user or external content
Jailbreaking

Usually tries to persuade a model to bypass its safety restrictions.

Targets model restrictions
Usually comes from the user
Prompt injection targets application instructions. Jailbreaking targets model restrictions. They can overlap, but they are not exactly the same — the next lesson explains jailbreaks in more detail.

Key Takeaways

  • • Prompt injection tries to change an AI application’s intended behaviour.
  • • It can be direct (in the request) or indirect (hidden in external content).
  • • Documents, websites, emails, and retrieved data are untrusted — treat them as data.
  • • Tool access raises the impact from a bad answer to a real action.
  • • Layered controls reduce risk but do not guarantee prevention.

Summary

Prompt injection happens when untrusted text tries to control an AI application. Safer systems preserve the intended task, treat external content as untrusted, limit permissions, check outputs, and require approval before important actions.
